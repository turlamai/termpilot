# TermPilot — 桌面嵌入式工作区设计契约

更新日期：2026-11-14（2026-11-23 按家族最小文档标准瘦身为可核对核心）。本文件只记语义、决策与边界，不记数值；产品仓库 `design/` 承载实现基线。

**真源分工**：颜色、字体栈、字号、圆角、间距与动效时长的具体值以 `design/prototype/shared.css` 为唯一真源（亮暗成对）；本文件只定义每个 token 的语义名与用途。改值改 CSS，改语义改本文件。

## 产品目标与本轮变化

面向嵌入式 Linux 与 MCU 开发，将串口与 SSH 作为同等重要的连接方式。覆盖“接开发板 → 配置连接 → 观察启动日志 → 收发命令 → 传输文件 → 启动外部调试工具”的日常流程。此前的主机库扩展为连接与设备，原有主机、设置、AI、安全原则与入口路径保持连续。

视觉方向沿用现有石墨灰、低饱和蓝和系统字体，终端输出始终是工作中心。macOS / Windows / Linux 共享术语、信息架构与交互逻辑；设备路径、快捷键修饰键和外部工具由平台决定。本轮是专业桌面工具原型，不添加移动产品范围。

## 文件与入口

- `index.html`：评审入口导航页，按各页 `<title>` 列出全部原型入口并链接本契约；默认进入连接与设备的入口是 `prototype/hosts.html`。
- `prototype/hosts.html`：连接列表、搜索、类型筛选、详情与类型专属配置。
- `prototype/workspace.html`：会话标签与独立双窗格，直接打开时使用明确标注为模拟的串口样例。
- `prototype/serial.html`：串口工作区快捷入口，与工作区共享同一实现。
- `prototype/sftp.html`：七种传输方式与队列，保留既有路径。
- `prototype/tools.html`：GDB / OpenOCD / ADB 外部工具流程。
- `prototype/palette.html`：AI 草稿入口。
- `prototype/settings.html`：外观、终端、非敏感 BYOK 配置、导入导出。
- `prototype/shortcuts.html`：统一键盘帮助与窄窗口资源入口。
- `prototype/shared.css`：设计 tokens、结构原语、共享组件与嵌入式布局。
- `prototype/app.js`：应用状态与本地模拟交互，无外部依赖。

单入口内导航保留会话与队列；刷新或另开 HTML 入口重置模拟会话。没有请求设备访问、网络服务、外部进程或 AI 模型。

## 信息架构

主要导航为连接与设备、工作区、文件传输、调试工具。资源管理保留端口转发、命令片段、密钥、已知主机；设置与快捷键位置稳定。窄窗口通过顶部导航与更多入口触达全部功能。顶端会话标签属于会话切换层，不与任务导航混用。

连接页先展示能力概览、类型筛选、列表与详情。选择名称查看完整详情，箭头直接连接。默认选中 UART 开发板示例。样例使用保留示例地址；设备路径明确标注为演示，不根据配置存在推断在线或网络延迟。

### 类型专属配置

先选择类型，再显示字段；切换类型保留名称与分组，并使用相应默认端口。

- 串口：设备路径、波特率、5–8 数据位、None/Even/Odd/Mark/Space 校验、1/1.5/2 停止位、None/RTS/CTS/XON/XOFF 流控、UTF-8/ASCII、发送行尾。实际组合是否支持取决于平台、驱动与设备。
- SSH / Mosh：地址、端口、用户、认证方式、密钥文件路径；安全与高级区包含 TOFU / 严格校验、跳板、Keepalive、启动命令。密钥路径仅记录元数据，不读取文件。
- Telnet / TCP：地址与端口，不要求 SSH 用户或密钥，并提示无传输加密。
- 本地终端：Shell 与工作目录。
- ADB：设备序列号与外部工具依赖说明。

字段错误使用可操作的中文说明，校验对应字段。保存编辑后，如对应模拟会话已打开，将其断开，重连时采用新配置，避免把已打开的传输通道静默改为另一种类型。

## 串口与终端工作区

### 独立会话与分屏

每个会话独立维护收发缓冲、计数、编码、过滤、历史、录制和定时发送。分屏可选择另一连接，两个窗格都有可工作的输入与输出。串口与 SSH 可并排使用；中等及窄窗口上下排列，而不压缩到不可读的列宽。辅助窗格关闭只收起布局，会话仍可从标签恢复。

### 收发与显示

- 文本与 HEX 接收显示可切换。HEX 按真实模拟字节格式化，不把字节值当作终端控制文本。
- 文本发送支持 None / LF / CR / CRLF；HEX 发送按完整字节校验，不隐式追加文本行尾。
- UTF-8 / ASCII 分别处理；ASCII 拒绝非 ASCII 发送字符，不伪称具备额外编码转换能力。
- RX / TX 计数根据模拟字节计算；控制信号事件不计入接收字节。
- 发送历史最多 100 项，选择器显示最近 10 项。
- 定时发送周期为 100–60000 ms，捕获启动时的消息内容；断开、设备异常、关闭会话、页面离开时停止。
- 对于串口，发送只记 TX，不捏造设备回应；“追加接收数据”显式生成 RX 示例。

### 日志

时间戳、文本筛选和正则筛选可即时更新；非法正则给出说明，不抛出界面异常。暂停滚动保留快照，接收仍继续，恢复后展示最新缓冲。每个会话缓冲最多 2000 行。

录制开始后捕获后续模拟数据，停止后可导出；未录制时导出当前模拟缓冲。日志文件带模拟声明，不描述成真实设备证据。录制记录仅在本次页面会话存在，不进入浏览器持久化。

### 设备状态与信号

原型可明确选择正常、设备占用、权限不足、设备拔出。异常时禁用发送、保留输出、停止定时发送，并给出对应处理建议。恢复正常后仍需用户显式重连。

BREAK、DTR、RTS 都先确认，再写入演示控制日志。RTS/CTS 流控启用时不允许手动切换 RTS。真实实现需尊重驱动支持，不在连接时静默翻转会影响复位的信号。

## 文件传输

传输方式为 SFTP / SCP / XMODEM / YMODEM / ZMODEM / TFTP / ADB。选协议后只列兼容的目标连接：串口协议绑定串口，ADB 绑定 ADB，SFTP / SCP 绑定 SSH 类连接。

开始前明确目标、方向、路径或串口通道、文件名；用户确认对端就绪后才创建任务。选择文件只读取文件名与大小，不读取文件内容，演示上限 10 MiB。失败演示在 60% 停止，保留失败状态并可重试；取消不会显示为完成。

SFTP 目录可新建、进入、返回、重命名、修改八进制权限、删除与下载。删除先确认；目录操作更新同一份模拟元数据。上传完成才在目标路径添加文件。下载只生成明确标为演示的文本回执，绝不把回执伪装为远程固件或真实文件。

SCP 不提供目录管理；X/YMODEM 要求 Bootloader 对端准备；ZMODEM 不假设所有终端都会自动识别；TFTP 明确信任网络前提。传输与固件烧录是不同动作，本轮不会执行烧录。

## 外部调试工具

GDB 配置可执行文件、ELF 与远程目标；OpenOCD 配置可执行文件、适配器配置与目标配置；ADB 配置可执行文件与设备序列号。

启动前展示 executable 与 args 参数数组，用户确认后才进入模拟输出；不拼接并执行 shell 命令。工具输出可导出，模拟进程可停止。OpenOCD 可进入 Telnet 控制台，并提供 RTT TCP 连接配置；9090 只是可编辑的示例端口，必须与外部服务配置匹配。GDB 提供本地模拟调试终端，不包含图形断点或寄存器 UI。

## SSH 资源与安全原则

端口转发支持本地 -L、远程 -R 与动态 -D。规则明确关联 SSH 连接，默认监听 127.0.0.1；动态代理不要求固定目标。规则启动仅改变模拟状态，不实际监听端口。

密钥管理与已知主机仅展示示例元数据，不读取真实凭据或改写本机 known_hosts。生产连接保留主机指纹验证，密码由实际终端输入，不写入连接导出。

## AI、偏好与数据

保留“AI 提议，用户执行”：目标输入 → 脱敏预览 → 明确确认 → 准备中 → 固定演示草稿 → 手动插入。插入只填输入框，不执行或发送。Esc 丢弃未插入草稿。AI 面板默认关闭。

原型只演示 IPv4 与常见令牌替换，不是完整生产脱敏器；不应输入真实秘密。解释选区只显示演示提示，不冒充模型分析。

保存内容仅包含连接配置、外观、终端字号和非敏感 AI 配置。API Key 不持久化，保存动作清空输入。浏览器存储不可用时以当前内存状态工作，不承诺刷新后保留。导入导出兼容串口、网络、本地与 ADB 字段；导入限制 1 MiB / 100 个连接，校验后确认替换并关闭模拟会话。

原有产品设置中的后端 SQLite、0600 文件权限、密钥哨兵等属于真实实现契约；不将浏览器原型的行为描述成已经兑现这些保证。

## 视觉与布局

延续上一版 palette 与组件，不新增装饰性渐变、玻璃、霓虹或无意义卡片。

| Token | 用途 |
|---|---|
| `--bg` / `--bg-raised` / `--bg-sidebar` | 画布 / 抬升表面 / 侧栏与活动区底色 |
| `--text` / `--text-dim` | 主文字 / 次级文字 |
| `--accent` / `--accent-hover` / `--accent-ink` | 低饱和蓝强调：交互入口 / 悬停 / 强调底上的前景 |
| `--border` / `--line` | 控件边界 / 发丝分隔 |
| `--selection` / `--hover` | 选中 / 悬停 quiet fill |
| `--error` / `--ok` / `--warn` | 错误 / 成功 / 警告（永远配文字） |
| `--terminal-bg` / `--terminal-size` | 终端底色与默认字号（终端配色与界面主题独立） |

系统 UI 字体、系统等宽字体，不加载外部字体或图片。页面标题（宽/窄两档）、正文、紧凑工具控件、终端默认字号、元数据各成层级（值见 `shared.css`），延续桌面专业工具密度。系统字号调整仍需真实宿主阶段验证。

终端六种配色与界面主题独立，分别设置前景、辅助色、成功色、路径色，避免浅色界面导致深色终端不可读。间距使用 4pt 网格；控件 / 列表·面板 / 对话框三级圆角；图标统一描边 SVG，均以 `.od-icon` 约束几何。状态配文字，不只用颜色。

布局以 grid / flex 正常流组织标题栏、导航、会话、终端和状态栏。断点行为：宽屏舒展 → 中宽双窗格上下排列 → 连接详情进入列表下方 → 导航重排 → 简化列表（具体宽度见 CSS 媒体查询）；最窄宽度保留全部核心动作，不禁止缩放。

保留 OD layout primitives 的 hidden 与关闭 dialog 规则。浮层使用原生 modal dialog、明确关闭入口、Esc、可见焦点与焦点返回。动作反馈短促（见 `--motion`），尊重 reduced motion。
