基本功，先做扎实

真实终端

每个会话一个伪终端：agent 密码提示、TUI 程序、vim、htop，行为与原生终端一致。标签页 + 分屏、主题、每主机字体、终端内搜索。

主机与分组

主机、分组、标签、备注，存本地 SQLite，一键导入 ~/.ssh/config。搜索到达即用。

系统 OpenSSH

ssh-agent、ProxyJump、known_hosts、config 兼容、新算法跟进——系统带来什么，TermPilot 就有什么。引擎层留有接缝，将来可换进程内栈。

Snippets

常用命令入库，参数占位符，分组管理；支持多会话广播执行。

端口转发

-L / -R / -D 规则图形化配置，绑定主机，随会话启停。

六种连接

SSH、本地终端、telnet、mosh、串口（波特率/校验位齐全）、SFTP——一个引擎，一套界面。

AI 原生，不是 AI 贴皮

⌘K 生成命令

用自然语言说意图，给出可直接运行的命令草稿。你确认，才发送。

选区解释

选中报错输出，得到「发生了什么、为什么、下一步」。中文报错中文答。

发送前脱敏

私钥、token、凭据、连接串——AI 出站前逐条匹配打码，预览展示打了几处、打掉什么。

BYOK，你的 key

GLM、DeepSeek、Qwen、Kimi、豆包、SiliconFlow、OpenAI、Anthropic、本地 Ollama——预设齐备。key 存 0600，引擎持有，永不进 WebView。

Agent 接口

确定性 JSON CLI 与 MCP：让 coding agent 列主机、跑单次命令、管 Snippets——AI 时代的原生接口。

不收 AI 税

AI 功能属于完整产品，不是订阅。你的 provider 记你的账，TermPilot 不抽成。

本地优先，就这么设计

没有账号，没有托管同步，没有遥测。主机、Snippets、会话历史存本地 SQLite，随时标准格式导出。AI 只在你调用时出站，且先脱敏。 你的密钥，你的数据，你的机器。
